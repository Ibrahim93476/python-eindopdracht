# python-eindopdracht

Eindopdracht Periode 1 Python - Gemaakt door Ibrahim en Yehor

## Over dit project

Dit project is gemaakt voor de eindopdracht van Python & GitHub.

Tijdens deze opdracht hebben we verschillende Python-opdrachten gemaakt. We hebben Git en GitHub gebruikt om samen te werken, onze code te beheren en wijzigingen te controleren via Pull Requests.

## Opdrachten

### 1. Variables

We gebruiken variabelen om gegevens op te slaan en weer te geven.

Bestand: `variables.py`

### 2. Lists

We leren werken met lijsten. We voegen items toe, verwijderen items en gebruiken lijsten in Python.

Bestand: `lists.py`

### 3. If-statements

We gebruiken `if`, `elif` en `else` om beslissingen te maken in onze code.

Bestand: `if-statements.py`

### 4. Loops

We gebruiken `while`- en `for`-loops om code meerdere keren uit te voeren.

Bestand: `loops.py`

### 5. Match-case

We gebruiken `match` en `case` om verschillende situaties en keuzes af te handelen.

Bestand: `match_case.py`

## Gebruikte technologieën

- Python
- Git
- GitHub
- Visual Studio Code

## GitHub-werkwijze

Voor deze opdracht hebben we gewerkt met:

- Branches voor verschillende opdrachten.
- Commits om wijzigingen op te slaan.
- Pull Requests om code te controleren.
- Code reviews om feedback te geven en te ontvangen.
- Merges om opdrachten samen te voegen in de `main`-branch.
